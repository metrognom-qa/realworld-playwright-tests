# RealWorld UI Tests

Automated UI tests for https://realworld.qa.guru/ using Playwright and JavaScript.

## Tools

- Playwright
- JavaScript
- Faker
- Page Object Model

## Test Scenario

### Create an article and verify it in the profile and Global Feed

1. Log in with a registered test account.
2. Create an article using randomized data generated by Faker.
3. Verify that the article page URL contains `#/article/`.
4. Verify the article title, body, and tag after publication.
5. Open the user's profile and verify the article appears in My Articles.
6. Open Global Feed and verify the article appears there.
7. Open the article from Global Feed.
8. Verify its title, body, and tag again.

## Project Structure

- `pages/` — page objects containing locators and actions.
- `tests/` — test scenarios and assertions.
- `playwright.config.js` — Playwright configuration.

## Setup

1. Install Node.js and npm.
2. Download or clone the repository.
3. Open a terminal in the project directory.
4. Install dependencies:

```bash
npm ci
```

5. Install Playwright browsers:

```bash
npx playwright install
```

6. Register a dedicated test account at https://realworld.qa.guru/.
7. In `tests/create-article.spec.js`, replace the credentials passed to `loginPage.login()` with your test account credentials. Do not commit passwords.

## Run the Test

Run in Chromium with a visible browser:

```bash
npx playwright test tests/create-article.spec.js --project=chromium --headed
```


## Current Limitations

- Test credentials are currently configured directly in the test file.
- The created article is not deleted after the test.
